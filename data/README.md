# Online data appendix, Who Owns Nashville? (October 19, 2026)

Every file below is cited from one of the seven papers. All derive from public Davidson County, Tennessee, Census, and SEC endpoints; the query strings are in each paper's footnotes.

| File | What it is |
|---|---|
| `OPERATOR_ROLLUP_CANONICAL_2026-07-22.csv` | Operator holdings of framework parcels, July 22, 2026 (Part I Table A1; cited by the Introduction and Part II). |
| `Operator_Name_Crosswalk_MASTER_2026-07-22.csv` | Recorded owner name to parent operator, with the evidence class for each attribution. |
| `Operator_Name_Crosswalk_ADDITIONS_2026-07-22.csv` | July 22 adjudications added to the crosswalk (Yamasa, FREO, Mile High to Progress; Sparrow / Nuveen; Invesco). |
| `PARENT_SUBSIDIARY_ADDRESS_REGISTRY_2026-07-14.csv` | Parent-subsidiary registry: 9,973 entities under 97 parent families, with Secretary of State addresses and Davidson deed presence (Part I Section 4.C). |
| `Burdened_Tract_ReRun_CANONICAL_2026-07-15.csv` | Per-tract entity and named-operator counts and rates with ACS 2020 to 2024 values and the burdened flag (Part I Tables A5 to A7). |
| `Table_ConcentrationRatios_CANONICAL.csv` | Burdened-tract concentration ratios, 1.23x entity and 0.88x named. |
| `Table6_Burdened_vs_NonBurdened_CANONICAL.csv` | Burdened against non-burdened tract summary. |
| `Table3_Top20_Tracts_by_EntityRate_CANONICAL.csv` | Twenty tracts with the highest entity share. |
| `Table12_Chilton_TTests_CANONICAL.md` | Welch t-tests, high-concentration against other tracts (Chilton Table 4 replication). |
| `PartI_Appendix_A3_owner_group_tiers_2026-10-19.csv` | Concentration of entity-owned parcels by owner-group size (Part I Table A3). |
| `PartI_Appendix_A8_operator_tract_ratios_2026-10-19.csv` | Operator appraisal-to-tract-median ratios and owner-majority-tract shares (Part I Table A8). |
| `PartI_Appendix_A9_operator_net_acquisitions_2026-10-19.csv` | Net acquisitions by operator and year, 2010 to 2026 (Part I Table A9). |
| `PartI_Appendix_A9_operator_gross_acquisitions_2026-10-19.csv` | Gross acquisitions by operator and year. |
| `PartI_Appendix_A10_occupancy_conversion_2015-2025.csv` | Owner-occupancy conversion shares of arm's-length sales (Part I Table A10). |
| `PartII_Appendix_A_registration_by_operator_2026-10-19.csv` | Landlord registration by operator on three measures (Part II Appendix Table A1). |
| `PartII_Appendix_A_registration_by_operator_REGISTRANT_2026-10-19.csv` | Registration by operator, registrant-name measure. |
| `PartII_evictions_operator_plaintiff_detainers_2026-10-19.csv` | 2,049 detainer warrants with a named operator as plaintiff: docket, date, plaintiff, parent (Part II). |
| `PartII_Registration_delta_new_2026_cases_2026-10-19.csv` | Landlord registrations issued January to October 19, 2026 (413), with institutional flags. |
| `PartIII_BTR_Share_RECONCILED_2026-07-15.csv` | Build-to-rent share of new single-family permits by year, strict and inclusive (Part III Table III.1). |
| `PartIII_BTR_parcels_by_tract_2026-10-19.csv` | Build-to-rent parcels of the named operators by census tract (Part III Table III.6). |
| `PartIII_PublicBuilder_Share_2026-07-03.csv` | National public builders' share of permits with a resolved builder (25.3 percent). |
| `PartIV_landbank_live_counts_2026-10-19.json` | Seventeen land-bank and option vehicles, parcels held June 24 and October 19, 2026 (Part IV Table A2). |
| `PartV_securitized_parcels_1833_entity_parcel_ownership.csv` | The 1,833 Davidson parcels ever pledged as SFR securitization collateral: borrower entity, parent, acquisition, instrument, coordinates (Part V Table A-1). |
| `PartV_securitized_parcels_points.geojson` | The same 1,833 parcels as points with deal, operator, ZIP, tract, council district. |
| `PartV_deal_geography_summary.csv` | 289 deals: whether the collateral schedule discloses city or state (Part V disclosure finding). |
| `PartV_validation_vs_freddie.csv` | Deal-by-deal validation against Freddie Mac's 2013 to 2018 SFR securitization list. |
| `PartV_securitized_by_zip.csv` | Securitized parcels by ZIP code (37013 = 878). |
| `Literature_Comparison_Matrix_2026-05-23.csv` | Literature comparison matrix: investor definition, single-family definition, period, geography, named operators, method, by study (Part I Section 4.B). |
