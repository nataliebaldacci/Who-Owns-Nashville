Methodology & data

This chart is built from a single per-parcel master that joins three primary Davidson County / Metro Nashville government datasets, one row per parcel:

  1. Ownership history (chain of title) — the recorded deed record, flattened to up to 20 owners per parcel with each owner's acquisition date, sale price, mailing zip, and mailing state. Source: Metro ParcelHistory ownership layer · ParcelHistory MapServer, Layer 2.
  2. Assessment history — the assessment class (R = Residential) and improvement (structure) value for every reappraisal year, from the Property Assessor. Source: Property Assessor of Davidson County (PADCTN), via the Cadastral MapServer, Layer 4.
  3. Property location — the property zip of each parcel, from the current cadastral. Joined to the ownership + assessment layers on the internal ParcelID.

How the population is filtered. For each Davidson reappraisal year (1993, 1997, 2001, 2005, 2009, 2013, 2017, 2021, 2025 — Davidson reassesses on a 4-year cycle, so only these years have full county-wide coverage), we keep parcels whose assessment class was R (Residential) and whose improvement value was > 0 (i.e., a standing structure — an actual home, not vacant land).

How the owner is identified. The owner "in place as of" each reappraisal year is the most recent owner in the chain of title whose acquisition date is on or before that year. Two non-owner-occupancy measures are then computed for that owner:

  • Absentee — the owner's mailing zip differs from the property's zip (the standard proxy for a home the owner does not live in).
  • Out-of-state — the owner's mailing state is not Tennessee (a stricter signal, most likely an investor or institution).

Caveats. Off-cycle years (e.g., 2000, 2003) are omitted because the assessor only records off-cycle parcels that transact or physically change, so they under-count. Property zip is the current cadastral zip (parcel location is stable).
