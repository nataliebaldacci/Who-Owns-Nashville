Every chart below is built from one per-parcel master — the flattened chain of title joined to the year-by-year assessment record. Class-R = Residential; arms-length = sale price > $1,000, excluding foreclosure trustee's deeds.

Methodology & data

All charts come from one per-parcel master (Parcel_Ownership_Assessment_ACS_FULL_FLATTENED_DEDUP) joining three primary Davidson County / Metro Nashville government datasets, one row per parcel, keyed on the internal ParcelID.

Datasets combined

  1. Ownership history (chain of title) — the recorded deed record, flattened to up to 20 owners per parcel, each with acquisition date, sale price, instrument type, and the owner's mailing zip & state. Source: Metro ParcelHistory, MapServer Layer 2.
  2. Assessment history — assessment class (R = Residential) and improvement (structure) value for every reappraisal year. Source: Property Assessor of Davidson County (PADCTN) via the Cadastral MapServer, Layer 4.
  3. Property location — the current property zip, from the current cadastral.

How each chart is filtered

  • Charts 1 & 2 (arms-length sales). The chain of title is exploded into individual sale events. We keep events with sale price > $1,000, parcel class = R at the reappraisal in effect at the sale, and instrument type ≠ "Trustee's Deed" (foreclosure deeds are removed, because they are not arms-length purchases and would otherwise inflate the out-of-state count during the crash years). A sale is an existing home if the parcel's improvement value was > 0 at that reappraisal — not year built. Out-of-state buyer = buyer mailing state ≠ TN.
  • Chart 3 (foreclosures). Exactly the Class-R events whose instrument type is "Trustee's Deed" — the foreclosure conveyances excluded from Charts 1–2.
  • Chart 4 (ownership stock). At each reappraisal year (Davidson reassesses every 4 years: 1993, 1997, 2001, 2005, 2009, 2013, 2017, 2021, 2025), we keep Class-R parcels with improvement value > 0, take the owner in place as of that year, and flag absentee (owner zip ≠ property zip) and out-of-state (owner state ≠ TN).

Caveats. Only reappraisal years have full county-wide assessment coverage; off-cycle years capture only transacting parcels and are excluded from the stock view. Property zip is the current cadastral zip. Quit-claim deeds (often intra-family) are retained in arms-length counts but flagged in the underlying data.
