Deeds of Trust Database

Every recorded deed of trust and assignment

The complete compiled record of deeds of trust, DOT assignments, amendments, and trust agreements recorded in Davidson County against the institutional single-family portfolios. Each row is a recorded instrument; where an instrument number exists it links straight to the county deed image. This is the collateral side of the story: which entity pledged which homes, to which trustee, for which lender, and how those security interests were later assigned up the securitization chain. Companion to the Deals database and Document Trail map.
